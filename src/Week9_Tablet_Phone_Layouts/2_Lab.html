Lab work

For this week's lab, show your knowledge of Responsive Layouts. You can use the example code posted on Github and follow the instructions from the lecture.

Modify your "Shopping List" application from the previous two weeks however this time implement the Master-Detail pattern in a reactive layout:

  1. Change the long-press gesture event to a Tap gesture. Whenever the user selects taps on an item from the list, it should show a details page on the right side when using a tablet or desktop screen. It should show the Item name, the quantity, and the database id. (1 mark)
  2. For a phone, or device in portrait mode, selecting an item from the list will show the Item name, the quantity and the database id on the page so that it replaces the list. (1 mark)
  3. The details page should have a "Delete" button that deletes the item from the list and from the database. (1 mark)
  4. The details page should have a "Close" button that just sets the SelectedItem variable back to null so that the DetailsPage doesn't show any more. (1 mark)

Demonstration

For your work to be assessed by the professor, you must demonstrate that selecting an item from the list shows the details page on a device in Landscape mode. Selecting an item in Portrait mode shows the details using the full page. When you delete an item, the details are no longer shown on the page.
