Lab work

For this week's lab, show your knowledge of Responsive Layouts:

Create a "To Do" list that lets users add items to a list. The user can type into a TextField and click "Add", the same as what you have had for the previous labs.

  1. Change the long-press gesture event to a Tap gesture. Whenever the user selects taps on an item from the list, it should show a details page to the right of the page on a tablet. It should show the Item name, and database id. (1 mark)
  2. For a phone, or device in portrait mode, selecting an item from the list will show the details of the item instead of the list. (1 mark)
  3. The details page should have a "Delete" botton that deletes the item from the list and from the database. (1 mark)

Demonstration

For your work to be assessed by the professor, you must demonstrate that selecting an item from the list shows the details page on a device in Landscape mode. Selecting an item in Portrait mode shows the details using the full page. When you delete an item, the details are no longer shown on the page.
