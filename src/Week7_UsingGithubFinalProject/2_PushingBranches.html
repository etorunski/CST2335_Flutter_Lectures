How to use branches in workflows

When you are going to work on a new feature, you want to keep your work seperate from other people's work so that they aren't affected by your changes. First of all, make sure that you have the latest code from the repository from the server by pulling from the server. For this, type in the command git pull. This will make sure that all commits on the server are also present on your computer.

Creating a branch

To create a branch, type in the command: git branch BRANCH_NAME but replace BRANCH_NAME with something you make up. This will create the branch but will not make it active. To activate the branch, type: git checkout BRANCH_NAME but with the name that you created.
Try that now by creating a branch called Delete_Comments. Then check out your branch. To make sure that the branch is active, type git branch. This should list all of the branches on your local computer, along with a star * next to the current branch. That means that all your commits will be saved to that branch. Go ahead now and remove the comments in main.dart. Since you have changed your file from the way it was committed, it should show up in the commit window:
In the command line, you can do the same thing by typing git status. This will tell you what files have changed from how they were last committed. This should tell you that main.dart has changed. To see the changes in main.dart, type: git diff main.dart. The lines in red are what were deleted and the lines in green with a + show you which lines have been added.

Go ahead and commit your changes onto your branch by typing: git commit -am "Removed Comments". This means that this change has been saved as a commit on the Delete_Comments branch. Go ahead and checkout the main branch and you will see that the file is back to how it was before because the main branch doesn't include your last commit. Checkout your Delete_Comments branch and see that your file is now the way you last saved it. Use AndroidStudio to push your branch to github through the git menu, or use the command: git push origin Delete_Comments. The origin is variable replacing the URL of the remote computer, and Delete_Comments is the branch name to push to on Github. To see what URL that origin is tied to, type: git remote -v
