Named routes

In order to support web sites, we can use named routes. Named routes let your app behave like a website:

  • /pageOne For going to page one
  • /pageTwo For going to page two

In the MaterialApp( declaration of your app, where you set removed the debug banner, you can also define the routes to your different pages: 

    MaterialApp(
        title: 'Named Routes Demo',
        initialRoute: '/',
        routes: {

            '/': (context) => const FirstScreen(),
            '/second': (context) => const SecondScreen(),
            '/otherPage': (context) => OtherPage(),
        },
    )

On the left side, you define the route's name followed by : and then the constructor of a page object that should be loaded when that route is loaded.
