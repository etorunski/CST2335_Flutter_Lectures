Git Branches

Using branches in Git means that you can add file changes on a different path. You can create a branch through the git menu. Click on New Branch.

Create a new branch called "Week3".

Now, whenever you commit changes, the changes will be applied to the Week3 branch instead of the main branch.

          children: [         ],
        )

Some Widgets only take 1 child, like Button, or the Center(). The Column() widget takes an array of children:[ ]. Let's add 4 ElevatedButtons: Button 1, Button 2, Button 3, Button 4:

This is what MainAxisAlignment.Center looks like. Let's commit these changes now so that we can go back to it later. MainAxisAlignment.Start makes all the children start from the top:

MainAxisAlignment.End makes all the children start at the bottom:

MainAxisAlignment.SpaceEvenly creates an even amount of space between the children and the top and bottom:

MainAxisAlignment.SpaceBetween makes the children line against the top and bottom and puts all the space between the elements.

MainAxisAlignment.SpaceAround is similar to SpaceEvenly except that the space at the top and bottom is only half that of the space between the elements.

Your options for spacing elements in a Column are:

  • MainAxisAlignment.center
  • MainAxisAlignment.start
  • MainAxisAlignment.end
  • MainAxisAlignment.spaceEvenly
  • MainAxisAlignment.spaceAround
  • MainAxisAlignment.spaceBetween

These parameters can also be used for Row() instead of Column. Column puts elements vertically, where Row lines them up horizontally from left to right.
