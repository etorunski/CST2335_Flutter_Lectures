Expanded widget:

Expanded basically makes a child widget grow larger, but it grows proportionally to its flex: parameter. Have a look at the demo widget at this website: Expanded class - widgets library - Dart API (flutter.dev) .

CachedNetworkImage: 

Cached Network Image lets you specify an Image's URL in the Widget constructor and then downloads it when the network is available. Once downloaded, it just reuses what it downloaded instead of reloading it. It does the same thing as you downloading an image to the assets folder ahead of time as you did in week 2. Have a look at this site: cached_network_image | Flutter package (pub.dev) and the video here: CachedNetworkImage (Package of the Week) - YouTube 

Padding:

The padding widget lets you set margins around the child: parameter. Have a look at this page: Padding class - widgets library - Dart API (flutter.dev) 

Flutter launcher icons on Android, iOS, and Web:

Have a look at this webpage: flutter_launcher_icons | Dart package (pub.dev)  . For these extra packages, you must install them using the commandline: 

flutter pub add flutter_launcher_icons

Basically, download a PNG or JPG to your images folder like we did in previous weeks. Look at the website for launcher_icons and follow the section on copying and pasting the parameters to your pubspec.yaml file: 

dev_dependencies:
  flutter_launcher_icons: "^0.13.1"

flutter_launcher_icons:
  android: "launcher_icon"
  ios: true
  image_path: "assets/icon/icon.png"
  min_sdk_android: 21 # android min sdk min:16, default 21
  web:
    generate: true
    image_path: "path/to/image.png"
    background_color: "#hexcode"
    theme_color: "#hexcode"
  windows:
    generate: true
    image_path: "path/to/image.png"
    icon_size: 48 # min:48, max:256, default: 48
  macos:
    generate: true
    image_path: "path/to/image.png"

The only thing to change is the image_path parameter for each of the android, ios, web, windows, macos sections. The web section also needs a background_color and theme_color HEX color, like #FFFFFF for example.

Then when everything is finished, just run this command to generate the icons for each specified platform:

flutter pub run flutter_launcher_icons

Then launch your app in Android or iOS and you'll see the icon has changed from default Flutter icon. On Web, you should see the icon at the top in the tab bar.

Circle Avatar

To get a circular shape around an Image, just CircleAvatar widget. CircleAvatar class - material library - Dart API (flutter.dev)  Set the backgroundImage: parameter as the picture you want to show but use an AssetImage() widget instead of Asset.image() as we did in Week 2. Also change the radius: parameter until the shape looks like what you want. Just follow this example:

CircleAvatar(
  backgroundImage: AssetImage('images/algonquin.png'),
  radius:100
);
