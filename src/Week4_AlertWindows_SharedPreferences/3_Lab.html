For week 4's lab, show your knowledge of AlertDialog, Snackbar and SharedPreferences:

Take your login page from your Week2 branch and add code so that whenever the user clicks on the login button, you show an AlertDialog asking whether the user would like to save their username and password for the next time they run the application.

If the user clicks "Yes" or "Ok" or whatever button you choose, then you will save the two strings to EncryptedSharedPreferences. If the user clicks "No" or "Cancel", then your application will clear any data that is saved in EncryptedSharedPreferences.

Next, add code so that when the program starts, you load the data in EncryptedSharedPreferences and if you find that the username and password are stored, then load it into the EditText fields. You should then show a SnackBar that the previous login name and passwords have been loaded.

The marks for this lab are: (5 marks)

  1. When the user clicks Login, you show an AlertDialog asking to save the login name and password.
  2. Clicking on the buttons of the dialog will either save or not save the strings.
  3. If you save the strings, then the next time you start your application, the strings are loaded into the TextFields
  4. You show a Snackbar if you have reloaded the strings from shared preferences.
  5. If you click on the "No" button on the AlertDialog, then the next time your start your application then the TextFields are empty.
