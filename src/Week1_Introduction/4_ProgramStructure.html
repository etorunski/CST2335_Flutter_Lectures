MyApp is a subclass of StatelessWidget, which is a class that can be drawn on a screen.

The StatelessWidget class has a build() function, which returns how this class should look on screen. This Build function returns a MaterialApp( ) object, which is like an HTML page, with a Title, Body, and Theme:

As you see, the Body is set to MyHomePage, which is below that in the file. The parent class is StatelessWidget means it's a Widget (something drawn on screen) that is Stateless (doesn't change). The home: parameter is a MyHomePage() class which is a subclass of StatefulWidget. It's a Widget that has State (it has values that can change).

If you look at the class, there is a _counter variable, which keeps track of the number of times the user presses the plus (+) button. The underscore letter at the start of the name makes it a private variable, function, or even private class. Notice that _MyHomePageState begins with underscore, so it's a private class

Comments

Dart uses DartDoc comments for commenting the code. It follows the JavaDoc format, meaning that you can write a single line comment by writing /// at the start of the comment. Multi-line comments begin by /** and end with */. You should write descriptive comments above every Class declaration, every class variable declaration (variables that are not in a function), and every function declaration that does not have @override. Functions that do have @override as part of their declaration inherit the comments from the parent class.
