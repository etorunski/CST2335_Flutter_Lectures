Documentation

Dart follows the Java commenting format: /** */ for comments, or /// for single line comments Let's look at the official Dart documentation guidelines for creating comments:
https://dart.dev/effective-dart/documentation
Make sure that you look at the "Doc comments" section for the DartDoc style. Notice that DartDoc supports MarkDown formatting in its comments.

You should comment your instance variables and the functions you declare. You don't need to comment variables that are declared inside of functions.

Dart has a library called DartDoc, which is equivalent to JavaDoc. To install the library, run the command: 

flutter pub add dartdoc

Once you have finished, you can generate the documents for your project by running the command: 

dart doc

This will create a /doc subfolder that has your documentation.

For more information about generating documentation, read this page: https://www.dhiwise.com/post/getting-started-with-dartdoc-tips-for-generating-dart-api-docs
