Updating the screen

Let's try replacing the Button widget with a Slider: https://api.flutter.dev/flutter/material/Slider-class.html

The Slider has several parameters

  1. value: followed by a variable that holds its current value. This should be a double
  2. onChanged: followed by the name of a function that handles a new double value when the slider is changed. You should create a function that takes a double, and assigns your value variable to be the parameter passed in.

Let's practice writing a function: 

  void setNewValue(double value)
  {
    numClicks = value;
  }

Then set the onChanged: parameter to the name of the function setNewValue. If you try running this, changing the slider won't change the text the way the button would do. This brings us to one of the main new concepts of Mobile Graphical Programming.

Redraw on variable update

In modern interfaces, the screen will only redraw when a variable has changed. If none of the variables have changed, then there is no need to redraw the screen. In order to indicate that we are changing a variable and we want the screen to update, we use the setState() function. 

    void setNewValue(double value)
    {
      setState(() {
        numClicks = value;
      });
    }

Here, we are updating the numClicks variable. By doing this, Flutter will optimize the redraw so that it only updates widgets that actually use the numClicks variable. Any widget that uses numClicks will get updated.

Layouts

To simplify layout management, you can only choose from Column, Row, or Box.

  1. Column lays out elements from top to bottom.
  2. Row lays out elements from left to right.
  3. Stack lays out elements vertically, from first at the bottom, and then everything else is laid on top of the previous items.
