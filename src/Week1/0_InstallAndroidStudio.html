Introduction

In this course, we will use AndroidStudio for developing mobile graphical user interfaces. You can download it from: https://developer.android.com/studio

Once you download it, run the installer process. Just choose the default options for installing it.

Android Studio is a program like Eclipse or NetBeans. You can edit code, launch the debugger and inspect how your program is running. You can set breakpoints and see what your variables are set to. You will also be able to choose to run your program in an Android device, in Chrome browser, or on your desktop.


Flutter

Flutter is a new technology that lets you write applications using a language called Dart. It is similar to Java and javascript but can be compiled directly to machine language, so it should run really quickly on a computer. Using Flutter, you can create an application once and compile it to Android, iOS (iPhone and iPad), to web app (Chrome or Edge) or to Desktop (Linux, Windows, Macintosh). Flutter was released in 2017 so it is still pretty recent however it is growing quickly.
