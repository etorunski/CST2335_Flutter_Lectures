Introduction

In this course, we will use AndroidStudio for developing mobile graphical user interfaces. You can download it from: https://developer.android.com/studio

Once you download it, run the installer process. Just choose the default options for installing it.

Android Studio is a program like Eclipse or NetBeans. You can edit code, launch the debugger and inspect how your program is running. You can set breakpoints and see what your variables are set to. You will also be able to choose how to run your program, either on an Android device, in a web browser, or on your computer.


Install Flutter

Once you have installed Android Studio, you must then install the Flutter SDK after:

  1. Go to https://docs.flutter.dev/get-started/install
  2. Choose your operating system version, and then select "Mobile" for your first type of app.
  3. Look down the page and download the zip file of the Flutter SDK to your computer. Extract the contents and then move the "flutter" folder somewhere on your computer where the path doesn't have any spaces in the name (So not "Program Files").
  4. Add the flutter\bin folder to your operating system's PATH variable.
  5. Then open Android Studio. On Windows, open "File" -> "Settings", and then find "plugins" in the list. On Macintosh, select "AndroidStudio" -> "Settings", and then find "plugins". Search for "Flutter" and install it.

You will have to restart the IDE after so go ahead and do so.

Flutter

Flutter is a new generation of multiplatform frameworks that lets you write code in one language, but then compile it for many other platforms. Flutter is similar to Electron and React Native, which uses JavaScript or Typescript to create the app, and then you can compile it for mobile, desktop or web.

Flutter uses a language called Dart to write an application, and then the Dart code gets compiled to native code. Microsoft launched a similar platform called MAUI (Multi-platform App UI) which uses C# and .NET to compile to machine code for different platforms. https://dotnet.microsoft.com/en-us/apps/maui

For now, your choice of platforms for running a Flutter app are:

  • Windows
  • Linux
  • Macintosh
  • Android
  • iOS (iPhone and iPad)
  • Web browser (Chrome or Edge)
    • .

Flutter also uses a new feature called Hot-Swapping of code, meaning that you don't need to restart your application to recompile your program.

Create a Flutter Project

  1. In Android Studio, select "File" -> "New" -> "New Flutter Project". Make sure to select "Flutter" on the left side, and select the directory where you unzipped the Flutter SDK.
  2. Give your project the name "test_flutter". For the Platforms, make sure everything is selected.

This will take some time to create the project Once it has finished, you should see this at the top of your screen: If you open the menu, you can see what platforms you can run your app on.

  1. From the compile target, select "Windows" and then Debug. However, for this to work, you must have Visual Studio installed. You must then also have the Desktop C++ tools installed in Visual Studio. You can get the free Community Edition from here: https://visualstudio.microsoft.com/vs/community/
    2. You should eventually see a Windows program running.
  2. Next, select a web browser "Chrome" or "Edge" and debug again. It will only debug on Chrome or Edge, Firefox and Safari won't work.

  4. If you have a Macintosh computer, you should also be able to select an iPhone emulator to run it.
