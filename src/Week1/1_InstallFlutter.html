Introduction

In this course, we will use AndroidStudio for developing mobile graphical user interfaces. You can download it from: https://developer.android.com/studio

Once you download it, run the installer process. Just choose the default options for installing it.

Android Studio is a program like Eclipse or NetBeans. You can edit code, launch the debugger and inspect how your program is running. You can set breakpoints and see what your variables are set to. You will also be able to choose to run your program in an Android device, in Chrome browser, or on your desktop.


Install Flutter

Once you have installed Android Studio, you must then install the Flutter SDK after:

  1. Go to https://docs.flutter.dev/get-started/install
  2. Choose your operating system version, and then select "Mobile" for your first type of app.
  3. Look down the page and download the zip file of the Flutter SDK to your computer. Extract the contents and then move the "flutter" folder somewhere on your computer where the path doesn't have any spaces in the name (So not "Program Files").
  4. Add the flutter\bin folder to your operating system's PATH variable.
  5. In Android Studio, open "File" -> "Settings", and then find "plugins" in the list. Search for "Flutter" and install it.

You will have to restart the IDE after so go ahead and do so.

Flutter

Flutter is a new generation of multiplatform frameworks that lets you write code in one language, but then compile it to another platform. Flutter is similar to Electron and React Native. These frameworks used JavaScript or Typescript to create the app, and then the native platforms were basically web browsers embedded as an application.

Flutter uses a language called Dart to write an application, and then the Dart code gets compiled to native code. Microsoft launched a similar platform called MAUI (Multi-platform App UI) which uses C# and .NET to compile to machine code for different platforms.

For now, your choice of platforms for running a Flutter app are: Windows, Linux, Macintosh, Android, iOS (iPhone and iPad), or Web browser (Chrome or Edge). Flutter also uses a new feature called Hot-Swapping of code, meaning that you don't need to restart your application to recompile your program.

Create a Flutter Project

  1. In Android Studio, select "File" -> "New" -> "New Flutter Project". Make sure to select "Flutter" on the left side, and select the directory where you unzipped the Flutter SDK.
  2. Give your project the name "test_flutter". For the Platforms, make sure everything is selected.

This will take some time to create the project Once it has finished, you should see this: To test compiling your app for different platforms, try the following steps:

  1. From the compile target, select "Windows" and then Debug. You should eventually see a Windows program running.

  2. Next, select a web browser "Chrome" or "Edge" and debug again. It will only debug on Chrome or Edge, Firefox and Safari won't work.
  3. You can also select to run it on an Android emulator. Select the emulator and debug it again.
  4. If you have a Macintosh computer, you should also be able to select an iPhone emulator to run it.

The important thing to understand about Flutter is that you just write the code once and you can run it on many different platforms.
