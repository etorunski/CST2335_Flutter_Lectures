Lab 1

This week, you have had a quick introduction to Flutter, and started programming in Dart.

For this week's lab, you should:

  • Change how the _counter variable is declared so that it uses var instead of double. Basically initialize the variable to 0.0 instead of 0.
  • Show that you can launch the program on the Android emulator, and a web browser (Edge or Chrome)
  • Declare another variable called myFontSize and have it initialized to 30.0. Change both the Text() widgets so that they use a TextStyle() object that are both set to that size. That way, whenever you change the 30 to something else, both lines of Text should change size to the new size with Hot Swapping. You will have to remove the const keyword infront of the Text()
  • Change the setNewValue() function so that it also sets your new myFontSize variable equal to the new value. This means that whenever you change the slider, your font size of the two lines of Text should change.
