A ListView is a widget like a Column where you can add many rows that are scrollable. For instance, your Email program normally shows a ListView of emails that you have received, or the "missed calls" list view shows you all the calls that you have missed on your phone.

Using functions to create components

Whenever you have several components that work together to create a portion of a page, it is helpful to use a function to isolate their construction and usage. Since a ListView normally also has a button and TextField for entering data, let's create a function that creates all 3 and returns them: 

    Widget ListPage(){
        return Column(  );
    }

Then for the Scaffold layout, we can just call the function for the body parameter: 

 body: ListPage(),

Now let's implement that function somewhere else in the file so that everything that has to do with the list view is impemented in the same place.

ListView

A ListView is a Widget that you would use when you don't know how many things ahead of time that you want to show in a list. The user can then scroll down the list if it is larger than the screen. To create a ListView, we use a ListView.builder( ) function. This follows the Builder pattern: 

 ListView.builder( )

We need to supply the number of rows to build using the itemCount: parameter. This tells the application how many rows we want to build. The next parameter is the itemBuilder: parameter which takes a function where you pass in the row number to build, and it should return a Widget object representing what goes in that row: 

 ListView.builder(
            itemCount: ,
            itemBuilder: (context, rowNum) {   } )

Normally, a program uses an ArrayList that can hold a variable number of objects. Java has the ArrayList< > object, but the same object in Dart is called List < >.

In Dart, List is initialized a little differently by using the array notation: 

    List<String> words =  [] ;
    //or with type inference:
    var wordsArray = <String>[ ]

To get the number of items in a List, there is a length property. In the ListView.builder function, you can use this as the number of rows: 

 ListView.builder( itemCount:words.length,

Now you can play around with what gets returned by the itemBuilder function. You can create more complex widgets using Row, Column or Stack. 

    ListView.builder(
            itemCount: words.length,
            itemBuilder: (context, rowNum) {
              return Row( mainAxisAlignment: MainAxisAlignment.spaceAround,
            children: [Text("Row number: $rowNum"), Text(words[rowNum])]) ; } )

Whenever you try to put a ListView inside a Column, it will crash because a ListView must know how much height is being given by its containing object. The Column must know how big each of its sub items are in order to calculate its height. This gives a circular dependency which causes the crash. In order to fix this, you can put the ListView inside of an Expanded( ) widget. Expanded is a widget that takes as much space as it can. So the Column ends up having a child Widget which takes as much space as possible, which would be the window size. The ListView can also know how big its parent container is. The code should look like this: 

    Widget ListPage(){
       return Column( children:[
            Expanded(child:
                ListView.builder( itemCount:words.length,
                    itemBuilder: (context, rowNum) {  return
                        Row( mainAxisAlignment: MainAxisAlignment.spaceBetween,
                            children:[

                            ]);
                    }
                )
            )
        ]);
    }

Adding items to your list

Let's add a TextField at the top of the screen so that the user can add words to the ListView: 

    Row( mainAxisAlignment: MainAxisAlignment.spaceBetween, children:[
        ElevatedButton( child:Text("Add item"), onPressed:() {  }  ),
        TextField(inputController: _controller )
    ]);

When you click the button, it will take the contents of the TextField and add it to the List. You should put that inside of a setState(() { } ) function so that the screen will update when items are added: 

() {
    setState(() {
        words.add( _controller.value.text );
        _controller.text = "";
        });
    }

Now when you click on the Add Item button, your test will show up in the ListView. How about deleting items from the ListView? Flutter has a Widget called ListTile( child: ). This object has two different event listener functions, some of which are:

  • onTap:
  • onLongPress: - for holding your finger / mouse for a long time

The ListTile also has a Title parameter, and a subtitle parameter. These are Widgets so you can use a whole Row layout. 

    ListTile(Title: Row(    ....), onTap: () {  }  )

When any of these gestures are detected, you can then remove an item from the List. Just be sure that removing from the List is surrounded by setState( () { } ) so that the UI will redraw.

Using other than String

You should create a separate Model class that will store the information for whatever you are wanting to put in your List, like TextMessage, Email, Address, Call Info, etc. Then modify the ArrayList to store those kinds of objects instead of Strings. You must modify the TextFields so that you can input all the information needed for the object. Then when you submit the information, just call the constructor of that class with the information from the user. Lastly, you need to modify the ListBuilder function so that it returns a layout to represent the information of one of the elements that are in the List
