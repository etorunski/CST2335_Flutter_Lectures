Lab work

For this week's lab, show your knowledge of ListViews:

Create a "To Do" list that lets users add items to a list. The user can type into a TextField and click "Add" which should then make the item in the List. Each item should have the row number on the left side, and the To do item to the right.
You should add a Long-Press gesture listener which will bring up a dialog box asking if the user wants to delete the item. If the user selects "Yes", then the item will be removed from the list. If the user selects "No", then nothing should change.

If the number of items is empty, then you should instead show a Text saying "There are no items in the list".
