Lab work

Create a new branch in your lab project for Week6. It can be a branch splitting off from main or any other week because you will be creating a whole new page from what was done previously.

You should go over the notes for this week's materials as well as the sample code provided. For this week's lab, you will demonstrate to your lab professor your knowledge of ListViews:

Create a "Shopping List" list application that lets users add items to a list, as well as the quantity. The user can type the item name into a TextField, and the quantity into another TextField, and click "Add" which should then add the item in the List.

You should create your own ListPage() function to implement this component and return it, as shown in class.

Each item should have the row number and the item name on the left side, the quantity to the right. 
You should add a Long-Press gesture detector which will bring up a dialog box asking if the user wants to delete the item. If the user selects "Yes", then the item will be removed from the list. If the user selects "No", then nothing should change.

If the number of items is empty, then you should instead show a Text saying "There are no items in the list".

The marks for this lab are (5 marks):

  1. Typing an item in the TextField and clicking the "add" button makes the item appear in the list.
  2. After inserting an item, the TextField is cleared so that the previous string is gone.
  3. If the user long-presses an item in the list, an AlertDialog appears asking if they want to delete the item.
  4. Selecting "Yes" from the AlertDialog removes the item from the list.
  5. Selecting "No" from the AlertDialog does not remove the item from the list.
