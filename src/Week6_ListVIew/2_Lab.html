Lab work

For this week's lab, show your knowledge of ListViews:

Create a "To Do" list that lets users add items to a list. The user can type into a TextField and click "Add". The item should then appear in the List, and there should be an empty checkbox on the same row. When the user clicks on the checkbox, it marks the item as finished. There should also be a bottom Navigation bar with two items:

  1. Current
  2. Finished

When the user clicks on "Current", the application should show the current list of to do items. When users click on the checkbox to finish an item, it should go into a second list of finished items. From the list of finished items, if a user selects the checkbox again, it will make the item current again, and it should appear in the list of current items.

In the finished items list, each item should have a Long-Press listener which will bring up a dialog box asking if the user wants to delete the item. If the user selects "Yes", then the item will be permanently deleted. If the user selects "No", then nothing should change.
