SQLite

Flutter is loosely based on Android, so it inherits SQLite from how Android implements it. However, SQLite uses a lot of common code (called boilerplate) to set up a database and queries. There are newer libraries that now generate the database code for you so it is easier to manage. One of the most popular libraries in Flutter is called the Drift library: https://pub.dev/packages/drift
The Drift library can be used for all platforms, including Web Applications. To get started, have a look at this tutorial: https://r1n1os.medium.com/drift-local-database-for-flutter-part-1-intro-setup-and-migration-09a64d44f6df

To install the Drift libraries, run these commands: 

    flutter pub add drift drift_flutter path_provider path  sqlite3_flutter_libs

    //These are development dependencies for compiling, not running, so add -d flag
    flutter pub add -d build_runner drift_dev

Next, create a new file to write the SQL create table statment for the table you will create to store your items. The file must have end with .drift. I'll use the name "table.drift". Within the .drift file, write your table creation statement in SQL:: 

CREATE TABLE UserTable (
    id INT NOT NULL PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL,
    music_style TEXT NOT NULL,
    favorite_song INT NOT NULL
) As User;

Then in the same file, write your CRUD statements as stored functions: 

    saveUser: INSERT INTO User (username, music_style, favorite_song) VALUES (:username, :music_style, :favorite_song);
    getAllUsers: SELECT * FROM User;
    getUserById: SELECT * FROM User WHERE id = :id;
    deleteUser: DELETE FROM User WHERE id = :id;
    updateUser: UPDATE User SET username = :username, music_style = :music_style, favorite_song = :favorite_song WHERE id = :id;

Next, add the supplied AppDatabase.dart file to your /lib folder. It's mostly boilerplate code for creating a database file. Just change the @DriftDatabase( include: { '____.drift'},) statement so that it matches the .drift file you created. The AppDatabase constructor calls super(openConnection() ); which will detect what platform you are running and create the appropriate file for storing your tables.
Then take the following files that are provided: 

    connection.dart    <<-- This file has a default implementation of openConnection()
    native.dart        <<-- This file has an implementation of openConnection for Android, iOS, Windows, Linux.
                            You can change the filename 'db.sqlite' if you want to something more meaningful.
    web.dart           <<-- This file has an implementation of openConnection for Web. You can change the filename 'my_app_db'
                            to something mre meaningful. This tells the browser to load sqlite3.wasm and drift_worker.js for the
                            database libraries. These two files must be moved into the /web folder of your project
    unsupported.dart   <<-- This is just there to give an error if you run your application on anything other than Web, Android, iOS, Linux, Mac, Windows

Once you have moved all the files into place, you must generate the table creation code in dart by translating your .drift SQL statements into dart code. run the command: 

dart run build_runner build

This will put the generated code in the file listed by the part command: 

    part 'AppDatabase.g.dart';   //<< This tells flutter where to put the generated code. It should appear after running the command.

If ever you modify the SQL table creation statement, you should remove your application from the device so that a brand new table file is created. Or, you can research how the MigrationStrategy() function works and you can specify how to modify your column data to the new format: 

  @override
  int get schemaVersion => 2;  // Increment the schemaVersion if you change the SQL create statement

 @override
  MigrationStrategy get migration {
    return MigrationStrategy(
      onCreate: (Migrator m) async {
        await m.createAll();
      },
      onUpgrade: (Migrator m, int from, int to) async {
         if (from < 2) {}
      },
      beforeOpen: (details) async {
         if (kDebugMode) {
          await validateDatabaseSchema();
        };
      },
    );
  }

Now in your program, call the constructor to create your Database: 

late AppDatabase db;

    //in initState( ):
     db = AppDatabase();

Now you can use your database object to call the stored functions you declared in the .drift file: 

    // 1. Insert a user (returns generated ID)
    db.saveUser('JohnDoe', 'Jazz', 101).then((id) async {
        //This is async because the database object must insert the data, and then find out what the id is that gets returned:
        usersList.add(  //Now that the id has been passed in, you can add it to your list of objects in memory:
                UserTable( id:id, username:'JohnDoe', musicStyle:'Jazz', favoriteSong:101  ));
    }
