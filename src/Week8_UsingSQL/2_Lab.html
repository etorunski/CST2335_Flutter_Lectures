Lab work

For this week's lab, you will use last week's lab where you used a ListView to show to-do items. You will demonstrate your knowledge of databases to save the items that are entered so that they can be loaded again when the application launches.

  1. Whenever the user clicks the "Add" button, you will now also add the newly created ToDo item to the Database using a DAO object and an insert function (1 mark).
  2. Whenever the application restarts, your List should contain all the items that were previously saved in the database. (1 mark).
  3. Whenever the user deletes an item using the long press, you should delete the item from the database. When you restart your application, it should not appear again (1 mark).

Demonstration

For your work to be assessed by the professor, you must demonstrate that adding items stores them in the database, restarting the application retains all the saved items, and deleted items do not appear the next time you run your application (3 marks).
