Lab work

For this week's lab, you will use last week's lab where you used a ListView to show to-do items. Create a branch called Week8 and you can use the lecture video and sample code in the CST2335_Fall2024 repository project as an example.
You will demonstrate your knowledge of databases to save the items that are entered so that they can be loaded again when the application launches.

  1. Whenever the user clicks the "Add" button, you will now also add the newly created ToDo item to the Database using a DAO object and an insert function (1 mark).

  3. Whenever the user deletes an item using the long press, you should delete the item from the database. When you restart your application, it should not appear again (1 mark).
