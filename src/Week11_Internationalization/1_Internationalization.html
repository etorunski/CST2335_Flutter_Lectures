Internationalization

This refers to supporting other languages for your application. There is a really good tutorial at this website:

https://www.flutterclutter.dev/flutter/tutorials/internationalization-i18n-in-flutter-an-easy-and-quick-approach/2020/213/

Basically are the steps are:

  1. Add "flutter_localizations:" section to pubspec.yaml
  2. Add translation json files to the assets/translations folder.
  3. Add those files to the assets: section of the pubspec.yaml file. This is the same section as the JPG and PNG images.
  4. Create the AppLocalizations and LocalizationsDelegate classes following the tutorial.
  5. Make sure that all your language JSON files are complete and are not missing any entries.
